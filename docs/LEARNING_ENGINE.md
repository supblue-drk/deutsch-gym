# Phase 2 学习引擎

## 内容

`src/data/expressions.json` 为项目编写的 60 条本地学习材料，非外部抓取、无远端加载。三个世界各 20 条；ID 为显式 `work-001` / `life-001` / `auto-001` 等，发布后不得重编号或复用于另一表达。CEFR 为教学定位，语域和注意事项用于区分正式会议与日常口语，不是官方考试认证。内容编译进主 JS，随应用外壳预缓存。

## 日课与持久化

日期使用设备本地年月日，非 UTC 截断。一个日期一个 `daily:YYYY-MM-DD` 会话，首次打开时保存队列及目标，后续继续同一队列。目标设置仅影响下一次新建日课。队列先按到期时间和稳定 ID 排序复习，再按三个世界轮流选未练习的表达；不补充已学习、已巩固或仍在学习阶段的表达来充数。内容不足时小于目标，全部练完可显示零条。

每个表达只有一个 `cards` 主键记录。每次评分将卡状态、会话游标、唯一事件 `sessionId:cursor` 一起写入单个事务。重复点击或旧游标不会重复记分。关闭应用后重开会话从上次成功保存的下一条继续；未评分卡的答案会重新隐藏。原始排程的时间戳保持不变，设备时区变化后不会重算既有到期时刻。

专门的 Review 会话只快照当前已到期的表达，支持中断恢复；完成后可以再次加载新到期项。Again 不强制立即反复出题，而是十分钟后再变为可用。日课在开始时取到期快照，期间新到期的条目可从 Review 开始。若同时打开多个会话或多个窗口，它们可包含相同表达；单会话评分幂等，跨会话的显式评分仍会影响该卡的最新排程。建议在一个窗口完成一项会话。

## 可解释的调度

`interval` 单位为日；`ease` 初始 2.5，限制在 1.3–3.0。首次卡片为 new，收藏仍是 new。

| 评分  | 下一次                                                  | ease  | 状态                                        |
| ----- | ------------------------------------------------------- | ----- | ------------------------------------------- |
| Again | 当前时刻 + 10 分钟；interval 重置为 0                   | −0.20 | learning，lapse +1                          |
| Hard  | max(1, ceil(interval × 1.2)) 日                         | −0.15 | 尚未学会则 learning，否则 review / mastered |
| Good  | 0→1，1→3，之后 max(interval+1, round(interval×ease)) 日 | 不变  | review / mastered                           |
| Easy  | max(4, round(interval×ease×1.5)) 日                     | +0.15 | review / mastered                           |

除 Again 外均到目标本地日的零点，按日历加日而不是固定 24 小时，兼容夏令时。日间隔封顶 365 天。Hard 的间隔比同一张卡的 Good 短；不保证比卡片上一次间隔短。间隔达到 21 日为 mastered；仍按到期日期复习，Again 会回到 learning。Good / Easy 首次设置 learnedAt，之后保留学习历史，Again 不抹除曾学过的事实。手动“标记已学”安排 Good 的首次间隔，但不冒充真实评分或增加 reviewCount；已学过的卡不会被手动标记改期。

`reviewCount` 统计全部实际评分，`lapseCount` 统计 Again，`lastReviewedAt` / `lastReviewedDate` 仅由评分更新。收藏和只读详情不触发排程。

## 指标口径

- 已学：learnedAt 非空；已巩固：当前状态 mastered。
- 今日到期：dueAt 小于次日本地零点，含逾期及今日稍后可用的 Again；现在可复习：dueAt ≤ 当前时间。
- 连续天数：有评分或新手动已学事件的不同本地日期连续计数；今天尚未活动时从昨天开始，跨过一个空白日则归零。
- Review 会话：已完成且至少处理一条的专门 review 会话，不把日课或未完成会话计作 Review。
- 七天活动：每日评分和首次手动已学事件数，非学习分钟；同一天多次活动不会虚增连续天数。
- 世界进度：该世界 learnedAt 非空卡数 / 本地表达总数。

## 数据安全与备份

v2 仅新增 `cards`、`learningSessions`、`learningEvents` 三表。Dexie 保留 v1 原表及所有数据，不需要清库、数据重编号或破坏性 upgrade。默认主题及目标仅缺失时补齐。旧骨架表不提供可映射到当前表达的学习事实，保留供备份，不伪造学习成绩。

备份格式 `app: deutsch-gym`、`version: 1`、`schemaVersion: 2`，包含偏好、新三表及 legacy 三表。导入校验版本、字段、枚举、有效日期、有限数值、主键唯一、已知表达 ID、队列游标、会话/评分事件关联，完整校验后才询问覆盖并以单事务替换；不接受部分合并或其他应用的文件。导入保留原来的绝对到期时刻和活动日，跨时区导入不会重写历史日期。

显式重置清理全部学习表和收藏，保留主题/目标；不会触碰文件中打包的内容。普通发布和 Service Worker 缓存更新没有 reset / clear 路径。没有云同步、后台通知或自动备份；iOS 存储回收及用户清除网站数据不受应用控制，应手动导出。文件下载/打开方式依 Safari 与系统版本，必要时用分享菜单存到“文件”。
