# 后续开发计划（未实施）

Phase 1：应用骨架、导航、主题、数据库 v1、PWA、测试与文档。本 PR 仅交付这一阶段。

## Phase 2 候选：内容与训练

确认内容模型、来源与版权；提供少量经审核的 B2–C1 职场、表达、汽车战略材料。设计训练流程与完成条件，写入真实 session 数据。明确离线内容包策略，新增 schema 版本与迁移测试。

## Phase 3 候选：复习与个人库

明确复习调度规则、时间边界和时区；实现用户收藏、个人表达及到期复习。补齐数据导出、导入与迁移恢复能力。

## Phase 4 候选：真实进度与质量

仅根据真实训练记录计算进度；定义统计口径。开展 iPhone Safari、离线更新、无障碍、存储回收与性能验证。是否引入同步或 AI 能力需另行确认，不默认接入任何付费 API。

每个阶段先确认范围和验收条件，再独立分支开发与 PR 审核。
